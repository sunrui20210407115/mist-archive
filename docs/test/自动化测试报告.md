## 二、测试入口与执行命令

测试用例按 hypium 规范组织，入口为 `entry/src/ohosTest/ets/test/List.test.ets`，由 `entry/src/ohosTest/ets/testability/TestAbility.ets` 拉起，运行器为 `entry/src/ohosTest/ets/testrunner/OpenHarmonyTestRunner.ets`。

```powershell
# 1. 构建测试 HAP
$env:JAVA_HOME='<DevEcoStudio>\jbr'
$env:DEVECO_SDK_HOME='<DevEcoStudio>\sdk'
& '<DevEcoStudio>\tools\hvigor\bin\hvigorw.bat' --mode module -p module=entry@ohosTest assembleHap --no-daemon

# 2. 安装并执行
hdc install -r entry-ohosTest-signed.hap
hdc shell aa test -b com.sunrui.mistarchive -m entry_test -s unittest OpenHarmonyTestRunner -w 30
```
